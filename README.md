# 🚔 POLINK Frontend

POLINK는 시민·경찰관·관리자가 사건 신고부터 수사 관리, 분실물·습득물 처리까지 관리할 수 있는 웹 서비스입니다.

이 저장소는 POLINK의 사용자 화면을 담당하는 프론트엔드 프로젝트입니다.

## 주요 기능

### 1. 인증 및 권한별 화면

- 회원가입 및 로그인
- 시민, 경찰관, 관리자 권한에 따라 메뉴와 접근 가능한 화면을 구분
- 로그인한 사용자 기준의 마이페이지 및 역할별 대시보드 제공

### 2. 사건 접수 및 사건 관리

- 시민의 사건 접수, 사건 목록 및 상세 정보 조회
- 사건 설명을 바탕으로 유사 사건을 검색하는 AI 사건 검색 화면
- 경찰관의 사건 목록 조회 및 수사 담당자 배정
- 관리자의 사건 관리 화면 제공

### 3. 수사 보드

- 사건별 수사 보드와 수사 진행 현황 조회
- 증거 자료, 참고인, 수사 일지, 가설을 한 화면 흐름에서 관리
- AI 수사 추론 결과를 조회하여 수사 가설 검토에 활용

### 4. 분실물·습득물 관리

- 분실물 및 습득물 등록, 목록·상세 조회, 조건 검색
- 작성자 및 경찰관 권한에 따른 물품 정보 수정
- 물품 이미지 첨부 및 상세 화면 표시
- 상태별 물품 조회와 시민 마이페이지의 내 등록 물품 확인

### 5. AI 분실물 매칭 및 반환 신청

- 자연어 설명에서 물품명, 특징, 장소, 날짜를 추출하는 AI 분실물 챗봇
- 보관 중인 습득물과 조건을 비교하여 유사 물품 제안
- 시민의 반환 신청 및 내 반환 신청 이력 조회
- 경찰관의 신청 정보 비교, 승인, 반려, 인계 완료 처리

### 6. 대시보드 및 통계

- 경찰관과 관리자 권한의 역할별 대시보드
- 분실물·습득물 유형 및 처리 상태 기반 통계 조회
- 사용자 권한 관리 화면 제공

## 기술 스택

- React
- Vite
- JavaScript
- CSS Modules

## 프로젝트 실행

### 1. 저장소 복제

```bash
git clone https://github.com/SemiProject-POLICE-ONE-POLINK/frontend.git
cd frontend
```

### 2. 의존성 설치

```bash
npm install
```

### 3. 개발 서버 실행

```bash
npm run dev
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:5173
```

> 정상적인 로그인과 데이터 조회를 위해 백엔드 서버가 함께 실행되어 있어야 합니다.

## 화면 구성

| 메뉴 | 주요 기능 | 사용자 |
| --- | --- | --- |
| 마이페이지 | 내 등록 물품, 반환 신청 이력 확인 | 시민 |
| 사건 목록·상세 | 사건 조회 및 상세 정보 확인 | 시민, 경찰관, 관리자 |
| 사건 접수 | 사건 신고 및 AI 유사 사건 검색 | 시민 |
| 수사 보드 | 증거, 참고인, 수사 일지, 가설, AI 수사 추론 관리 | 경찰관 |
| 역할별 대시보드 | 업무 현황 요약 확인 | 경찰관, 관리자 |
| 분실물·습득물 | 등록, 조회, 상세, 검색, 수정 | 시민, 경찰관, 관리자 |
| AI 분실물 챗봇 | 자연어 설명을 통한 보관 중 습득물 검색 | 시민 |
| 반환 신청 | 반환 신청, 내 신청 내역 조회 | 시민 |
| 반환 처리 | 신청 비교, 승인, 반려, 인계 완료 | 경찰관 |
| 통계 | 물품 유형 및 처리 상태 통계 조회 | 경찰관, 관리자 |
| 사용자 권한 | 회원 역할 조회 및 권한 관리 | 관리자 |
